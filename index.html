📦 Install in 60 seconds

Python 3.10+ and Node.js 18+ required.

1

Clone the repo

git clone https://github.com/DarkBytee/DuckAi.git cd DuckAi
2

Install dependencies

pip install -r requirements.txt npm install
3

Run it!

python duck_cli.py
🎙️ Optional voice features: pip install -r requirements-voice.txt — full guide in the README.
